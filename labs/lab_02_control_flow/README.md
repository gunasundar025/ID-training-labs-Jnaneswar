# Lab 02: Decisions and loops

**Learn:** comparisons, `if`/`elif`/`else`, `while`, `for`, and input validation.

**Task:** implement `classify_guess(secret, guess)` in `starter.py`. Return `"low"`, `"high"`, or `"correct"`. Build a guessing game that repeats until correct and counts attempts. Reject inputs that are not integers.

**Done when:** all three outcomes work, invalid input does not crash the game, and you tested first-try and multi-try completion.
