# Lab 03: Functions

**Learn:** defining functions, parameters, return values, default arguments, and scope.

**Task:** implement `calculate(first, operator, second)` for `+`, `-`, `*`, and `/`. Return the result. Raise `ValueError` for unknown operators and division by zero. Make a CLI that uses this function.

**Done when:** arithmetic and both error cases are covered by tests; the CLI can perform repeated calculations until the user exits.
