# Lab 06: Object-oriented Python

**Learn:** classes, instances, methods, dataclasses, and encapsulating state.

**Task:** model a small library with `Book` and `Library` in `starter.py`. A book has a title, author, and checked-out state. The library can add books, find books by title (case-insensitive), check out an available book, and return a checked-out book. Invalid transitions should return `False`.

**Done when:** adding, searching, checkout, and return work; duplicate titles are handled consistently; state transitions have tests.
