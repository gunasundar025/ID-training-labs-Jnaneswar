# Lab 04: Collections

**Learn:** lists, dictionaries, sets, iteration, and comprehensions.

**Task:** implement `add_contact`, `find_contact`, and `remove_contact` in `starter.py`. Store contacts in a dictionary keyed by normalized (lowercase, trimmed) name. Adding an existing name updates its phone number; looking up or removing a missing name returns `None` or `False` respectively.

**Done when:** add, update, search, and delete work, including names with extra spaces or different capitalization. Build a menu-driven contact book.
