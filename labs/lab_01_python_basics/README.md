# Lab 01: Python basics

**Learn:** running Python, variables, strings and numbers, `input`, printing, and type conversion.

**Task:** implement `convert_temperature` in `starter.py`. It accepts a Celsius number and returns Fahrenheit using `C × 9/5 + 32`. Then make a small CLI that asks for Celsius and displays the result. Handle non-numeric input with a friendly message.

**Done when:** the function returns numeric results, the CLI works, and you have tested zero, a negative value, and invalid input.
