# Lab 07: Modules and testing

**Learn:** imports, package layout, `unittest`, test fixtures, and logging.

**Task:** refactor one earlier lab into a small package with separate logic and CLI modules. Add unit tests for normal behavior, edge cases, and errors. Replace diagnostic `print` calls in program logic with the `logging` module.

**Done when:** importing the logic does not start the CLI, the CLI runs with `python -m`, and tests run with `python -m unittest discover -s tests -v`.
